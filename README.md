# ①課題名

見たい作品リスト

## ②課題内容（どんな作品か）

見たい映画やアニメなどを登録し、視聴済みかどうかを管理できるアプリです。

- 作品名を入力してリストに追加できます。
- 見終わった作品にはチェックをつけられます。
- 不要になった作品は削除できます。
- 登録件数と視聴済み件数を確認できます。
- Local Storageを使っているため、ブラウザを閉じても登録した作品とチェック状態が残ります。

## ⑤工夫した点・こだわった点

- 見たい作品と視聴済みの作品がひと目でわかるように、チェック状態に応じて表示を変えました。
- 登録件数と視聴済み件数を表示し、リストの状況を把握しやすくしました。
- パソコンだけでなく、スマートフォンでも使いやすいように画面幅に合わせてレイアウトを調整しました。
- Local Storageに保存できなかった場合は、画面にメッセージを表示するようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）

- 作品の配列をLocal Storageに保存するために、`JSON.stringify()`で文字列に変換し、読み込み時に`JSON.parse()`で配列に戻す処理を実装しました。
- 追加・チェック・削除のたびに、保存データと画面の表示を更新することを意識しました。
- 次回は、作品のジャンルや感想を登録できる機能や、「見たい」「視聴済み」で絞り込む機能に挑戦したいです。
